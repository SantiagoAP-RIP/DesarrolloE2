# 03 - Desarrollo

El codigo fuente ejecutable del proyecto se encuentra en la raiz para funcionar directamente con XAMPP. En esta carpeta se documenta la implementacion y se incluye una copia organizada del codigo en `src/`.

## Ejecucion

Iniciar Apache y MySQL en XAMPP y abrir `http://localhost/DesarrolloE2/`.

## Tecnologias

PHP 8, Apache, MariaDB/MySQL, PDO, HTML/CSS, Ollama y modelo local `llama3.2`.
